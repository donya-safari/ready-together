# Ready Together · Rainbow Leads

An early prototype of a bilingual (English/Persian) digital tool that prepares children and parents for paediatric surgery, starting with tonsillectomy.

Live demo: https://donya-safari.github.io/ready-together/

This is a research prototype for demonstration only. It is not a medical device and is not intended for clinical use. All doctor names and clinical content are examples.
